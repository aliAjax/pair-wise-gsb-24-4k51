# hxwl-10 考古探方记录

遗址探方、地层关系与出土物坐标档案（可落盘的闭环原型）。

## 技术栈

React + Vite + TypeScript + CSS，localStorage 落盘持久化。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 闭环规则

- **落盘一致**：探方、地层、出土物、修订链、冲突记录每次变更即写入 localStorage，刷新后完全一致；另支持导出 / 导入 JSON 档案。
- **地层承接**：新地层顶深自动承接上层层底（首层为 0），底深必须大于顶深且不得超出探方深度，否则记冲突。
- **坐标归并**：坐标（E/N/深度）在同一探方内唯一；重复坐标的出土物只能归并到同一标本编号并累加件数，指定其他编号即冲突。
- **闭合约束**：未闭合地层不得登记出土物；出土物深度必须落在所属地层顶深—底深范围内。
- **移交冻结**：移交（单个或整探方）后冻结坐标与件数；冻结标本拒绝归并。
- **修订留痕**：冻结标本的更正只能新建带原因的修订，原值永久保留在修订链中；未移交标本可直接更正。
- **冲突透明**：所有冲突列出探方、地层、坐标、原值、新值五要素，并保留在冲突记录面板中。

## 目录

- `src/types.ts` — 探方 / 地层 / 标本 / 修订 / 冲突数据模型
- `src/lib/store.ts` — 闭环校验与状态迁移（纯函数 `applyAction`）、落盘与示例档案
- `src/App.tsx` — 三栏工作台界面（探方 / 地层与出土物 / 冲突与修订链）
